# web-bugbounty-manual
--------------------------------------
Справочник по Web Security, веб-уязвимостям, Bug Bounty и CTF.
Материалы для изучения веб-уязвимостей, методов тестирования безопасности, Bug Bounty и CTF. Включает теорию, примеры, полезные инструменты и ссылки на дополнительные ресурсы.

Проект ориентирован на начинающих и тех, кто хочет систематизировать знания в области веб-безопасности.
--------------------------------------
Язык: русский.
--------------------------------------
Важно: материалы предназначены для обучения и использования в легальных лабораториях и системах, на тестирование которых получено разрешение.
--------------------------------------
При разработке проекта использовались инструменты искусственного интеллекта. Они помогали с написанием кода, структурированием материалов и отдельными исследовательскими задачами.

Результаты работы ИИ проверяются, тестируются и при необходимости дорабатываются автором проекта.
--------------------------------------
