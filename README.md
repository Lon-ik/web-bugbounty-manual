# web-bugbounty-manual
--------------------------------------
Справочник по Web Security, веб-уязвимостям, Bug Bounty и CTF.
Материалы для изучения веб-уязвимостей, методов тестирования безопасности, Bug Bounty и CTF. Включает теорию, примеры, полезные инструменты и ссылки на дополнительные ресурсы.
--------------------------------------
## Файлы

| Файл | Версия | Что это |
|------|--------|---------|
| [`web-bounty-v1.html`](web-bounty-v1.html) | web-bounty v1 | Терминальная редакция справочника (ноябрь 2026). 37 исходных разделов, payload'ы, deep dive, CVE-таблица. |
| [`web-bounty-v1.1.html`](web-bounty-v1.1.html) | web-bounty v1.1 | Редизайн: собственная тёмная техническая дизайн-система, переработанная навигация, учебная справка по каждому разделу, код-блоки с определением языка и копированием, исправленные CVE-строки и ссылки. |

Обе версии — **один автономный HTML-файл** каждая: открываются двойным щелчком в браузере, не требуют сборки, сервера и интернет-соединения (внешние ссылки открываются только при наличии сети).

### Что нового в v1.1

- Собственная дизайн-система вместо терминального неона: приглушённая тёмная палитра, системные шрифты, контраст WCAG AA (5.2:1 … 14.1:1).
- Полностью переработаны навигация (сворачиваемые группы, синхронизация с фильтрами), главный экран (реальная статистика, категории, продолжение чтения) и режим чтения.
- У каждого из 48 разделов — учебная справка: зачем раздел, что знать заранее, где искать, как подтвердить, ложные срабатывания, impact, исправление, что запомнить, первоисточники, связанные темы.
- Код-блоки получили определение языка и кнопку копирования с честным результатом.
- Исправлены ошибки в CVE-таблице (React-версии, CVE-2026-126187, CVE-2026-94482, SharePoint 53771, TeamCity, диапазон GHSA-2464) и заменены 3 нерабочих ссылки.
- Доступность: `<main>`, inert для закрытого мобильного меню, ловушка фокуса, focus-visible, `prefers-reduced-motion`, печать без интерфейса.
